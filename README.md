# Smooth Scroll Bookmarklet

###### :robot: Made by Clankers :robot:

---

#### This is intended to imitate the smooth scroll effect on Windows OS that's present when you middle-click.

- This code only works with content viewed on your web browser.
- Some sites appear to be able to block the script execution, so it's not guaranteed to work everywhere.

## How to Install

1. Navigate to minified.js
2. Copy the file contents
3. Right-click on the browser's bookmarks bar
4. Add page
5. Name it whatever you like (scroll/↕️/↕/⇅/⇵)
6. Paste the copied JS code for the URL
7. (Optional) [Add a favicon](https://stackoverflow.com/questions/521040/how-to-have-favicon-icon-set-when-bookmarklet-dragged-to-toolbar)

## How to Use

- Enable (Standby): Click Bookmarklet
- Disable: Click Bookmarklet
- Scroll Down: Down Arrow
- Scroll Up: Up Arrow
- Stop Scrolling: Press the same arrow again
- Slow Down: Left Arrow:
- Speed Up: Right Arrow
